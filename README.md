# Portafolio personal - Sebastian Rojas

## Descripción

Este proyecto consiste en un portafolio personal
desarrollado para la actividad integradora 1 de
Programación de Sistemas Web.

El sitio contiene información personal, habilidades,
proyectos académicos y un formulario visual de contacto.

## Tecnologías utilizadas

- HTML
- CSS

## Cómo visualizar el proyecto

1. Descargar los archivos del repositorio.
2. Abrir el archivo index.html en un navegador web.
